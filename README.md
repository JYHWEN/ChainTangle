# ChainTangle

ChainTangle is a decentralized, distributed network system manager that enables auto-scaling, high-availability clustering.

ChainTangle is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainTangle.git`
2. `cd ChainTangle`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainTangle is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
